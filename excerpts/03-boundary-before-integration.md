# Excerpt — writing the boundary before writing the integration

**Component:** evaluation of a small typed decision component beside the agent loop
**Status:** parked by choice, awaiting access; **not** in the production path

## The idea under evaluation

Whether a small typed probabilistic decision component can carry judgement that the platform
currently spends a large generative model on — for example output scoring, routing between
workflows, retrieval ranking, context-retention scoring, or cheap semantic gates.

Not a replacement for the main or delegated generative models. An adjacent component.

## The boundary written before any code

While access is pending, the project is paused and the following are explicitly forbidden —
verbatim from the project's own status document:

- do not install an SDK;
- do not create an API client or provider implementation;
- do not join a waitlist or contact the vendor on the owner's behalf;
- do not call the service, shadow live traffic, or add broad production logging;
- do not integrate the component into the platform, gateway, routing, board, memory or any
  civic-work system;
- do not send private, municipal, client or personal data to the provider.

## The first authorised phase, if it ever starts

One low-risk call site, isolated from production and from private or personal data. Success
criteria, label definition, evidence fields, cost ceiling and stop conditions agreed **before**
any collection or call. Explicitly: do not instrument every surface at once, and do not build a
generalised provider layer merely in anticipation of a tool that may never clear procurement.

## Why this excerpt is here

It is the clearest example in the repository of the principle that a privacy and procurement
boundary is a **design artifact**, not a legal afterthought. The project produced no deployed
integration — and is still worth documenting, because the discipline of writing down what an
experiment must never touch is the transferable part.

The status line a reader is meant to take away: **parked, with the restart conditions written
down.**
